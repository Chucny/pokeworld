# Pokeworld
<img src="logo-300.png" width="300" height="300" alt="Pokeworld logo">

Pokeworld is a Pokemon AR game like Pokemon GO
### Features
- AR: Catch Pokemon in AR! There's no map. Pure AR and fun.
- Inventory: Inspect your caught pokemon in your inventory
- Accounts: Save your progress to a Pokeworld account!
